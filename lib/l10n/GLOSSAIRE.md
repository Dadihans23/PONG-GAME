# Glossaire de Tilto (français, anglais, espagnol)

*Key terms of the game and the translation chosen in each language, with the reason. Reviewers: if you change a term, change it everywhere (see `RELECTURE.md` / `relecture.csv`) and note it here.*

Le français est la langue d'origine. Les traductions suivent le ton du jeu : tutoiement, phrases courtes qui disent quoi faire, vocabulaire de jeu vidéo plutôt que technique. L'espagnol est **neutre** : compris de l'Espagne à l'Amérique latine, tutoiement « tú », jamais de « vosotros » ni de régionalisme (ni « ordenador » ni « computadora », ni « coger », ni « celular / móvil » : on dit « teléfono »). Quand une phrase s'adresse aux deux joueurs, l'espagnol passe par un sujet à la 3ᵉ personne (« ambos teléfonos estén… », « los dos deben… ») pour éviter « vosotros / ustedes ».

## Termes du jeu

| balle | ball | pelota | « Pelota » est neutre ; « bola » sonne plus billard. |

## Ce qui ne se traduit jamais

- Les valeurs enregistrées ou envoyées sur le réseau : difficulté (`Facile`, `Normal`, `Difficile`), nom de la partie annoncé (`Partie de Tom`, relu par `hostNameOf`), pseudo par défaut `Joueur`, clés Hive, messages du protocole. Deux téléphones dans deux langues différentes jouent ensemble : chacun affiche dans la sienne.
- Les journaux (`debugPrint`, `pong.net`, `tilto.studio`).
- La présentation du studio, écrite dans l'administration du site (l'app la demande dans sa langue : `?lang=`).
